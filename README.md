# MINI MOMO – USSD Agent & User Management System

This project is a mobile money simulation system using PHP and MySQL that supports agent and user interactions through a USSD interface.

## Features

## AdminCredential
Email: admin123@gmail.com
password: Admin@123

### Admin Panel
- Secure admin login
- Register new agents
- Update agent balances
- View agent list and balances

### Agents
- Agents will be registered by Admin through web app
- Log in using their phone number
- Approve pending user registrations
- Check their balance

### Users
- Register through USSD
- User registered will start with initial 5000 default
- Send money to other users
- Withdraw money and make Deposit through Agent
- Check balance
